# Flash Client

Flash Client is an independent, Windows-first Minecraft launcher prototype built with Electron, React and TypeScript. It is still in development and is not available as a public release.

The current prototype includes local profile management, Modrinth content browsing and installation, launcher settings, and launch-readiness checks. Microsoft account sign-in and game launching are not yet implemented.

## CurseForge integration

Planned CurseForge API use is to search mod and modpack metadata and support compatible content installation where third-party distribution is permitted. The integration is optional and requires an approved API key; it is unavailable without one.

## Source availability

This repository contains public project information only. Flash Client's implementation source is kept in a separate private repository. No source code, builds, or credentials are published here.
