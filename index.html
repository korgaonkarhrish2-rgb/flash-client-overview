Independent launcher prototype

Make room for the way you play.

Flash Client is a Windows-first Minecraft launcher prototype focused on profiles, content discovery, and a clear path from setup to play.

Explore the projectIn development · No public release
Current prototype

A practical foundation.

The current Electron, React, and TypeScript prototype brings core launcher workflows into one place.

01 / ORGANIZE

Local profiles

Create and manage local game profiles with version and loader choices.

02 / DISCOVER

Modrinth content

Browse and install supported community content for compatible profiles.

03 / PREPARE

Launcher controls

Adjust settings and review launch-readiness checks before playing.

In progress

What comes next.

Microsoft account sign-in and game launching are not yet implemented. CurseForge integration is planned for mod and modpack discovery and compatible installation, subject to API approval and third-party distribution permissions.

The CurseForge integration remains optional and unavailable without an approved API key.
